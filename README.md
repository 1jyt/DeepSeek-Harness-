# DeepSeek Harness 工具集

一批围绕 [DeepSeek Harness](https://github.com/deepseek-ai) 的 Web 端小工具：给聊天界面铺自定义壁纸。

> 本仓库是一组独立小工具的合集，每个子目录都有各自的说明。

---

## 目录 Contents

| 目录 | 作用 | 说明文档 |
|---|---|---|
| [`firefly-dsh-wallpaper/`](firefly-dsh-wallpaper/) | 流萤壁纸 v3：深色壁纸 + 半透明界面 + 自动轮播 + 文件夹扫描 + 弹窗不透明修复（含示例图片，可打包发给他人） | [`firefly-dsh-wallpaper/README.txt`](firefly-dsh-wallpaper/README.txt) |

---

## 快速概览

- **壁纸**：把 `firefly-dsh-wallpaper/firefly-wallpaper.js` 放进 DSH 前端 `dist` 目录，并在 `index.html` 的 `</body>` 前加一行 `<script src="firefly-wallpaper.js"></script>`，再强刷页面即可。详见 [`firefly-dsh-wallpaper/README.txt`](firefly-dsh-wallpaper/README.txt)。
